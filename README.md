## 📚 Topic

## 🎯 Task Requirement

* 📥 Loading the dataset

* 🔍 Checking dataset information
* 📊 Generating summary statistics
* ⚠️ Checking missing values
* 🧹 Handling missing values
* 🗑️ Removing duplicate records
* 💾 Saving the cleaned dataset

## 💡 Project

### 🎓 Student Performance Data Analysis & Cleaning

The `students.csv` dataset contains student information and subject scores.

The dataset was analyzed and cleaned using **Python and Pandas**.

### 🔄 ML Workflow


---

# 🧹 Data Cleaning

Missing numerical values are handled using the **mean of the corresponding numerical column**.

Missing text values are replaced with:

```text
Unknown
```

Duplicate records are removed using Pandas.

The cleaned dataset is then saved as:

```text
cleaned_students.csv
```
